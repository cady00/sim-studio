# 局限与未实现路径

这份清单来自一次全仓检索：空函数体、`TODO` / `FIXME`、`not implemented`、`placeholder`、导入器直接失败、以及会把通用数字当成数据表的路径。能接上真实行为的已经接上。其余条目保持失败或明确拒绝，不返回假数据。

## USDA 与窄相提前结束

- USDA 由仓库自己写 ASCII。层级、局部变换、三角形、UsdPreviewSurface、UsdPhysics 刚体/碰撞/质量/关节，以及机器人路径的时间采样会写出再读回。坐标是毫米，`metersPerUnit` 是 0.001，Z 轴向上。不链接 OpenUSD。二进制 crate、引用、payload、变体集不展开；`upAxis = Y` 不旋转；多于三条边的面扇形剖成三角形。结构校验是 `validateUsdaText`。`usd-core` 26.8 能打开写出的舞台并认出预览表面、刚体、质量和转动关节；该包没有 `usdchecker` 命令。
- 碰撞全量查询仍返回原来的接触列表。`overlaps` 和 `detectBoxMesh` 按距离和上一帧命中排序，分离轴确认到一次命中就停。布尔值和全量结果非空一致。`rankLearned` 没有权重。1600 三角形的命中检测加速比 1080，脱靶约 1.04。同一谓词下 RRT-Connect 加速比 835，路径与调用次数不变。数字来自一次 RelWithDebInfo 全量测试。

## Process Simulate `.cojt`

导入器是自写的，不链接 Process Simulate。目录、`.jt` 所在的 `.cojt` 文件夹，或根元素为 AddFlow 的 XML，会读 `kin_graph.xml`、`motionparameters.e`、KUKA `KRC/R1/Mada/$machine.dat`，以及文件名就是 `.info` 的限位（libstdc++ 把 `.info` 的扩展名看成空）。私有样件留在 `testdata/local/cojt/`，不进版本库。

- 这份 KR210 的 `kin_graph.xml` 没有关节边。6 个轴来自 `$machine.dat`。软限位是 A1 −185..185、A2 −140..−5、A3 −120..168、A4 ±350、A5 ±125、A6 ±350 度。电机转速除以减速比得到的最大速度是 A1 116.796、A2 111.451、A3 112.000、A4 179、A5 172、A6 220 度/秒。文件里没有直接的轴加速度；`$AXIS_JERK` 没有当成加速度，规划仍受速度限制。A5 只耦合 A6，比值 −188/21461。A4 同时耦合 A5 和 A6，不写入单一 `coupledTo`。
- 几何取 `$TIRORO.Z` 645、`$LENGTH_A` 330、`$LENGTH_B` 1150、`$TX3P3.X` 1220、`$TFLWP.Z` 215，单位毫米。`$TX3P3.Z` 的 115 没有并进 `a3`。没有场景节点时，数学零位法兰是 (1765, 0, 1910) mm；A2=−90°、A3=90° 时是 (615, 0, 760) mm。A2 软限位不含 0°，关节值 0 会被夹到 −5°。
- KR210 的 JT 10.0 放进场景 387479 个三角形，并挂到名称对应的连杆。原先没解开的 3 个高度数面掩码 LOD 现在有三角形，各级 LOD 的和是 608701；它们不是最细的一级，场景三角形数不变。名为 ax 的节点没有细长网格，Z 又和父连杆重合，没有当成关节轴。轴向用 KUKA 数学约定写在 CAD 父连杆的局部坐标里：A1 的世界轴是 Z，A2 和 A3 是 Y。A4 在父连杆里是 +X，变到世界后大约是 (0.996, 0, 0.087)，因为装配连杆不是 `$TX3P3` 那个数学帧。
- 地轨 `irbt6004_0_d_10m_01` 做成外部轴 E1。JT 9.1 放进场景 30236 个三角形（各级 LOD 解开的和是 49385，场景只留每组 Range LOD 里三角形最多的那一支）。没有运动文件和机器数据。网格进来之后，行程取包围盒最长边 11568 mm，来源记为 mesh bounds，不是组件名里的 `10m`，也不是软限位。速度是 0。
- FANUC R-2000iB 的 `joint_max_speed` 小于 20，按 rad/s 换算：J1 100°/s，加速时间 1.2 s，加速度 83.333°/s²，来源记为 `motionparameters`。J6 是 210°/s。没有轴架和 DH，轴用 +Z，来源写明这不是测得的轴向。JT 9.1 放进场景 30261 个三角形，各级 LOD 解开的和是 50059。
- IRB6700 的限位来自 `.info`：A1 −170..170、A2 −65..85、A3 −180..70、A4 −300..300、A5 −120..120、A6 −360..360。没有速度。轴是 +Z。JT 9.1 放进场景 111545 个三角形，各级 LOD 解开的和是 180070。原先因高度数面掩码没解开的 1 个 LOD 现在有三角形，但它不是该组最细的一级，场景三角形数不变。
- KR420、KR280、KR6 的 cojt 没有 kin_graph，没有 MADA，也没有关节速度。KR420 只有区域，medium 的笛卡尔区是 20 mm。没有机器数据时腕部长度写成 0，不用结构体默认的 400 mm。JT 9.1 放进场景的三角形是 KR6 21915、KR420 418625、KR280 418625。各级 LOD 解开的和分别是 36904、666844、666826。KR420 和 KR280 各 8 个高度数面掩码 LOD 已经从文件解出三角形，场景比只解低度数掩码时分别多 116652 和 116648。
- 和 STEP 拟合对比：圆柱锚点是 shoulder 515.7、d1 390.6、a2 1302.9、a3 1277.3、d6 317.6 mm，速度用公开数据表。cojt 给不出这些长度和速度。示例路径 `cycle` 在数据表速度下是 3.200 s。把每个点的 zone 改成这份 cojt 的 medium 20 mm 之后，仍然是 3.200 s。
- `settle` 和 `delay` 会读入，但不加进梯形。线性轴减速比没有可换算的样件。`$AXIS_DIR` 只记在来源里，不翻转几何。导入姿态保持文件里的装配位姿，不套 `$AXIS_HOME`。
- 文件菜单「机器人库」从本机目录列出 `.cojt` 文件夹和 `.cojt.zip`，并再往下看一层嵌在别的 zip 里的 `.cojt.zip`。列表可以按品牌和型号过滤。预览用组件里的 `preview.bmp`，没有就不显示。选中的组件交给原来的导入器，运动学和 JT 网格挂到连杆上，资源名是组件文件夹名。同一型号若目录和 zip 都在，按名称导入时用目录。默认路径存在这台机器的 QSettings（`library/cojtRoot`），不写进工程，也不进版本库。加密 zip 会拒绝。Zip64 不读。

## 这次补上的空路径

- `MainWindow::runScriptSnippet` 原先是空函数，脚本停靠栏也没有入口。现在「运行片段」把编辑器里的源码交给 `IScriptHost::execute`，标准输出和异常写进脚本日志。场景里还没有脚本时会先建一条名为 `snippet` 的脚本。
- 运动学面板「建议连杆」原先对每根关节都套 `RevoluteLimit` 的缺省值（±180°、90°/s）。资源名包含 `kr420` 且建议出 6 个转动关节时，改为 `kr420DatasheetLimits()`（A1–A6 的公开行程和速度，见 `docs/KR420.md`）。

## 算法和数据用了简化，调用方看得到边界

- 建议连杆不再写 180°/s²。没有扭矩和惯量时，加速度来源是速度限制，节拍只受 `maxSpeed` 约束。非 KR420 的建议限位仍是 ±180°、90°/s。资源名含 `kr420` 且建议出 6 个转动关节时，行程和速度用公开数据表。用户输入的加速度来源标成「用户」；有扭矩、质量和负载时标成「动力学」，并按负载折减。
- 同一 STEP 里离关节轴较远的零件不会被收进这台机器人（径向超过 600 mm 和 5 倍圆柱半径中的较大值）。第二台机器留在原地。
- 焊点可达性把打开文件时已经相交的零件对当成装配接触。新的相交要深过 2 mm 才把该焊点标成碰撞。分组轴和真实转轴不完全重合时，大角度仍会报碰撞。
- `addKr420TrackDemonstration` 里滑台的速度和加速度是 1500 mm/s 与 1500 mm/s²。公开 KL 数据表没有用在这两个数上，源码注释已标明。
- DXF：直线、圆弧、圆、多段线、均匀三次样条、三维面、椭圆。填充按图案线（角度、基点、偏移、虚线）裁到边界里；实心填充没有图案线时用平行线铺满。尺寸有尺寸线、箭头和用笔画出来的文字。INSERT 会递归展开块里的块。
- glTF：图元上的形态目标按节点或网格的权重加进顶点。权重为 0 时形状不变。
- URDF：`package://包名/路径` 会在 URDF 所在目录、它的上一级，以及 `ROS_PACKAGE_PATH` 和 `SIM_PACKAGE_PATH`（冒号分隔）里查找。网格按米读入后再乘 1000 和缩放，变成毫米。找不到文件时这条网格失败，不造一个假零件。
- 图像嵌入是 ZIP 里的字节，不是 GIS。
- 焊点自旋搜索不对每个转角做碰撞，只在选中的姿态上做一次接近检查。修正建议是一次正逆解试探。
- 连杆包络是网格包围盒角点沿关节样本（步长不超过 20°）的凸包。没有连杆网格时，球腕模型用四段解析臂杆。不是三角面沿螺旋运动的连续扫掠。
- 避障是关节空间双向 RRT。直线段已无碰撞时结果就是起点和终点。连接失败会退回直线段。
- KUKA：有 PTP、LIN、SPL、SLIN、SPLINE / ENDSPLINE、`$TOOL` / `$BASE`（XYZABC）、INTERRUPT 和 IO。没有完整 BAS，没有工具标定数据。中断文本会保存并再次写出，仿真不执行中断程序。`$VEL_AXIS` 不作为指令往返。
- ABB：`confdata` 置零，未使用的外部轴写成 `9E9`。
- FANUC：只有 ASCII LS，没有二进制 TP。
- 齿轮、凸轮、电子凸轮、位置/速度控制器、限位、气缸、抓手、发生器和收集器只在内置求解器里积分。Jolt 不跑这些装置。
- Jolt 没有沿曲面骑行，网格碰撞体是凸包。网格对网格、连续碰撞和多点接触在内置求解器里。没有重写 Jolt 的 CCD。
- 机器人目录有 KR6_R900、IRB120、LRMate200iD、GP8 四条。限位、速度和连杆原点抄自 `docs/ROBOTS.md` 里的公开页面，资源的 `source` 写着链接，待用户核实。LR Mate 的 J3 在 xacro 里是 −70° 到 +205°，产品页写的行程是 420°。这四条没有公开的关节扭矩和连杆惯量，加速度来源是速度限制，不是 180°/s²。连杆网格是 ROS-Industrial 的 STL，包许可证没有单独的网格再分发说明，所以不入库；首次使用下载到 `~/.local/share/SimStudio/catalog-meshes`，`SIM_CATALOG_MESH_DIR` 只读本地目录，`SIM_CATALOG_MESH_OFFLINE=1` 不访问网络。下载失败的连杆仍是方盒。没有找到 KR 280 R3080 的公开网格，双机演示里第二台仍是橙色方盒，用户可以自己导入 STEP。导入 URDF 或 xacro 时，若关节写了 `effort` 且连杆写了质量，加速度改由扭矩和惯量估算，网格随视觉节点进入机器人资源。
- 序列编辑器用操作树旁边的时间轴画工序，过渡把后一道工序推迟到前一道结束加延迟，信号事件可以在工序开始或结束置位，另一道工序可以等这个信号。欢迎页的「打开示例工程」装入 IRB 120 焊装单元（布局、焊点、路径、夹具、`part_seen` / `weld_done` / `clamp`、节拍），不用 KR 420 的 STEP。
- 示波器在仿真步进之后记下勾选的信号和关节指令，横轴是仿真时间。关节速度和加速度是相邻采样的后向差分，第一步记 0。游标读的是该时刻之前最近的一个采样。导出的 CSV 第一列是时间，关节列可以带 `.v` 和 `.a`。轨迹最多保留 240000 行。它不记录网格接触力。软 PLC 不另做一条曲线，定时器完成位写进 `plc_` 加地址的布尔信号，映射出去的设备信号仍用原来的示波器。
- 内置软 PLC 的一条支路是串联（与），多条支路是并联（或）。触点可以是电平、上升沿或下降沿；沿比较的是上一拍扫描结束时的电平，第一拍把上一拍当成假。计数器 CTU 在梯级功率的上升沿加一，计数值达到预置后完成位置位。CTD 在上升沿减一，可以减到负数，计数值小于等于 0 时完成，不会自动装入预置。CTR 在梯级为真时把计数清零，完成位仍按计数值是否达到预置来判断。一条与支路里的触点可以再或上同级触点，写在该触点的 `or` 数组里，只嵌一层。接通延时 TON 在输入为假时把已计时间清零。断开延时 TOF 在输入为真时完成并清零已计时间，输入掉下去之后继续计时，达到预置才落下；没见过真输入的定时器保持断开，预置为 0 时第一次假输入就落下。一次物理步最多补 8 个扫描，周期取工程里的 `scanSeconds`，小于 0.1 ms 时按 0.1 ms。扫描在逻辑块之前、物理步进之前，所以光电要到下一步才能进 PLC。强制盖住该地址的输入和输出。输送机只有写了 `signal` 才看运行许可；信号名为空时仍按原速度走。OPC UA 交换只接受十进制节点号上的布尔，客户端没连上时记一行日志，设备映射照常。工程格式版本是 11，旧工程没有 `softPlc` 时按关闭的软 PLC 打开。停止仿真会清定时器和计数器的过程值，不清程序和强制。导入机器人资源后追加未接线的布尔草稿：`Rn_AtHome`、`Rn_Busy`、`Rn_Fault` 为输入，`Rn_Start`、`Rn_Grip` 为输出。外部轴追加 `En_InPos` 输入。设备信号留空，不强制。纯外部轴不占用机器人序号。`softPlc.zones` 是干涉区，形状 `sphere`、`box`（轴对齐包围盒，`size` 是半长）或 `cylinder`（竖直圆柱，`size` 的 X 是半径、Z 是半高）。监视节点原点或机器人 TCP，写出 `名字_Occupied`（可改地址）。`softPlc.collisions` 用现有网格碰撞查询写出 `Rn_Collision`。两者都是布尔输入，强制后扫描不再改写。每个物理步只查一次网格碰撞，干涉区每个扫描都测。扫描日志可导出 CSV，列是时间、扫描号、信号和值。旧工程没有 `shape` 时按球打开，没有这两项时按空列表打开。`softPlc.cycles` 在每次扫描里监视选定信号的上升沿或下降沿，并刷新工序树和甘特图。起始沿打开工序；写了 `busySignal` 时，结束沿要等该信号在本周期里曾经为真才收口。`blockSignal` 为真的区间写成名为「干涉阻塞」的工序，甘特条用琥珀色。旧工程没有 `cycles` 时不生成这些工序。规则可以写 `resource`，甘特图按这个资源分行，同一个资源的规则共用一行。瓶颈是排程秒数最多的那个资源。`resource` 指向气缸节点，或场景里只有一个气缸且规则监视 `资源_Extending` 时，扫描在活塞离指令终点超过 1 mm 且伸出命令为真时把该位置位。旧工程没有 `resource` 时仍按原来的工位分行。
- 运动学页的关节滑块按当前关节的下限和上限拖动位置，松手之前就作用到连杆。视口拾取选中包含该零件的最内层连杆，以及以它为子连杆的关节。姿态库列出当前机构已记录的姿态，记录和运动到姿态读写同一份列表。`--demo devices` 里的转台、滚床和升降机只通过 `ensureResource`、`addLink`、`adoptParts`、`addJoint` 和 `capturePose` 搭出来。
