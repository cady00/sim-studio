# 外部轴

手臂仍然是 6 轴。第七轴以及变位机是用户自己建的运动学资源，再挂到机器人上，不是预制的地轨类。关节记成 `E1`…`E6`，和 KRL 的外部轴同名。这里不写后处理器，只把以后导出要用的名字存下来。

## 用户怎么建

1. 在运动学页新建一台设备，用连杆和移动副（或转动副）做出导轨、滑座，或 1～2 轴转台。限位、速度、加速度写在这些关节上。
2. 选中机器人，填写导轨设备名、安装连杆（滑座或转盘），类型选「直线地轨」或「变位机」，按「挂成外部轴」。
3. 导轨的连杆和关节会抄到机器人资源后面，关节名变成 `E1` 起。机器人根连杆重新挂到安装连杆下面，世界位姿不变。`KinLink::mountedOn` 记下这次安装。原来的导轨设备还在，节点是同一批。

运动链是 **底座 → 地轨 → 机器人**。变位机不进这条链：它转的是工件，不挪机器人底座。

地轨演示 `--demo kr420track` 也走这套接口。导轨和滑座是盒子，只为了看得见，不是一种机器类型。速度 1500 mm/s、加速度 1500 mm/s² 是占位，没有拿 KUKA KL 的样本。本机上 KR 420 沿 +X 走 8000 mm 的同步直线，节拍是 **6.333 s**（381 个采样）。手臂自己的臂展是 3076 mm，这段比它长，时间由地轨的梯形曲线决定，不是由笛卡尔 5000 mm/s 决定。

## 逆解里的冗余

手臂关节保持在列表前面，外部轴追加在后面。数值逆解只对最多 6 个手臂关节做阻尼最小二乘，外部轴不进那张 6×6 矩阵。

`redundancy.mode`：

| 模式 | 行为 |
| --- | --- |
| `fixed` | 用 `fixed` 里的外部轴位置；不够的轴保持种子。权重不起作用 |
| `travel` | 在行程上采样，少离开种子 |
| `midrange` | 同样采样，关节靠近限位中点 |
| `manipulability` | 同样采样，平移可操作度更大 |

三个权重 `travel`、`midrange`、`manipulability` 会一起算。界面上的三个预设把权重设成 (1, 0.05, 0)、(0.05, 1, 0)、(0.05, 0.05, 1)。代价是行程项 + 中位项 − 可操作度项，可操作度先按本次采样里的最大值归一。

一根外部轴采 9 个等分点，并带上种子。两根采 5×5，并带上种子。第三根以及更后面的轴在搜索里停在种子上，不展开。

可操作度用的是平移雅可比的 `sqrt(det(Jv Jvᵀ))`，不是 6×6 行列式。球腕工具沿 +Z 时 `q5` 接近 0，整条 6×6 几乎处处奇异，分不出伸直和弯曲。对 `a2 = 400`、`a3 = 300` 的这台球腕，目标在世界 x = 700 mm 时，平移可操作度的峰值在肘大约 63°（地轨约 100 mm），不在肘 90°（地轨 200 mm），因为底座回转的力臂在那里更长。伸直（地轨 0）会被丢掉。

球腕和 SCARA 的正解只把 `externalKind == "track"` 的关节当成刚体前缀。变位机关节不移动工具点。网格机器人（`ik = numerical`）走连杆链，安装关系已经在链里，不再加一遍前缀。解析球腕的关节角不能套回 KR 420 的网格。

## 路径

路径和路径点的 `external`：

| 值 | 行为 |
| --- | --- |
| `locked` | 这一段外部轴保持起点。默认就是这个 |
| `sync` | 直线地轨（移动副）跟 LIN / CIRC 一起走。沿地轨方向的位移由滑座承担，工具点留在直线或圆弧上 |
| `positioner` | 点的位姿在工件坐标系里。工件帧的 `link` 指向转盘。外部轴目标写在点的 `externalValues`，顺序与外部关节一致 |

一段的时间是笛卡尔梯形和每根在动的外部轴梯形里更长的那个。参数 `u` 跟最慢的那根走，所以工具点不会先跑完、地轨还在赶。节拍因此含外部轴。

PTP 本来就按每根关节的速度和加速度拉齐，外部轴的限位同样生效。

「可达性」把第一根地轨从下限扫到上限，逐点锁住再求逆解，数有多少个点够得着。

## 项目文件

外部轴字段从格式版本 6 开始。当前常量是 11，读取器仍打开 1 到 11。版本 6 的文件若没有这些字段，关节不是外部轴，连杆没有 `mountedOn`，冗余模式是 `fixed`，路径是 `locked`。
